# ADR-0010 — MCP는 AI의 필요 시 조회/검색 도구, 읽기 전용 DB 접근

- 상태: `TARGET-DESIGN` · 최초 기록: 2026-11-18 (제공된 v7/업무 정의를 반영한 **팀 검토용 재구성**)
- 결정 주체: 프로젝트 팀(승인자/승인일 미입력). 이 문서는 라이선스/성능·실배포 검증 증거가 아님.
- 연결 요구사항/근거: `EV-10, NFR-04, BR-B06`

## 맥락 — 문제가 무엇이고 왜 결정이 필요한가

AI 그래프가 조회/검색을 쓰는 방법이 분산되면 권한·데이터 형식·외부 호출을 점검하기 어렵다.

## 선택한 방향(팀 v7/업무 설계의 목표)

MCP Tool 서버가 공식 웹 검색/페이지/문서 파싱, 공고·프로필·벡터 검색을 표준 도구로 노출. DB는 읽기 전용/학생별 권한 제한, 결과 저장·Checkpoint는 Agent Server/업무 저장 계층이 담당한다.

## 검토해야 할 대안(비교 목록)

- Agent 그래프에 외부 HTTP/SQL 코드를 직접 분산
- MCP에 모든 쓰기/행정 권한 부여
- 도구 없이 LLM에 데이터 복붙

**선택 기준:** 도메인 정확성·학생 경험·작업 유실 위험·현재 팀 인력과 운영 부담·교수님의 대규모 가정. 대안이 정량 비교되었다는 주장은 하지 않는다.

## 얻는 것

도구 경계·권한 검증·Mock 교체 용이

## 감수할 대가 — 단점도 기록

추가 서버·네트워크 홉·스키마/인증 관리, 도구가 늘면 운영 복잡도 증가

## 무엇을 검증해야 이 결정이 유효한가

권한 우회·다른 학생 데이터 요청·SQL write 실패·mock 도구 호출·네트워크 오류 시험

## 되돌리거나 변경할 조건

도구 수와 비용이 작고 추가 서버의 복잡도가 이익보다 크다면 라이브러리 호출로 합칠 수 있음

## 구현·검증 상태

`[ ] 팀 승인` `[ ] 코드 대응 확인` `[ ] 실패 시험 통과` — 세 체크 모두 **검증 전**. ADR이 있다는 이유로 이 항목을 체크하지 않는다.
