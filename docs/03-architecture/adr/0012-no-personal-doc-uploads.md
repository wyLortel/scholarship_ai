# ADR-0012 — 개인 증빙서류는 업로드·보관·진위 검증하지 않고 발급 방법만 안내

- 상태: `TARGET-DESIGN` · 최초 기록: 2026-11-18 (제공된 v7/업무 정의를 반영한 **팀 검토용 재구성**)
- 결정 주체: 프로젝트 팀(승인자/승인일 미입력). 이 문서는 라이선스/성능·실배포 검증 증거가 아님.
- 연결 요구사항/근거: `EV-06, BR-C05, BR-C06, BR-C07, BR-C08, FR-C03, FR-C04, FR-C05`

## 맥락 — 문제가 무엇이고 왜 결정이 필요한가

기존 계획은 서류 처리까지 포함했으나 v6에서 범위를 변경했다. 증빙 파일은 민감정보·보존·진위검증·보안 부담이 크다.

## 선택한 방향(팀 v7/업무 설계의 목표)

학생에게 공고별 필요한 서류와 공식 발급/확인 경로를 안내. 학생은 외부 발급·확인 후 직접 제출한다. 서비스는 제공한 사실 기반 작성 초안만 다룬다.

## 검토해야 할 대안(비교 목록)

- 학생 증빙 파일 수집·검증
- 외부 발급기관 API 연동
- 서류 안내 자체 생략

**선택 기준:** 도메인 정확성·학생 경험·작업 유실 위험·현재 팀 인력과 운영 부담·교수님의 대규모 가정. 대안이 정량 비교되었다는 주장은 하지 않는다.

## 얻는 것

개인정보 수집 최소화, 구현/법적/운영 위험 축소, 원래 사용자의 신청 준비 목표에 집중

## 감수할 대가 — 단점도 기록

학생이 실제로 서류를 발급했는지 자동 확인 불가, 수작업 부담은 남음

## 무엇을 검증해야 이 결정이 유효한가

서류 업로드 UI/API가 없는지, 체크리스트에 발급 경로가 있는지, 다운로드만으로 제출완료라고 표시하지 않는지 테스트

## 되돌리거나 변경할 조건

사용자 검증과 법무/보안 요구가 바뀐 경우 별도 PRD 변경+보안 설계+새 ADR 필요

## 구현·검증 상태

`[ ] 팀 승인` `[ ] 코드 대응 확인` `[ ] 실패 시험 통과` — 세 체크 모두 **검증 전**. ADR이 있다는 이유로 이 항목을 체크하지 않는다.
