- 사용자 행동(When):
- 눈에 보이는 결과(Then):
- 금지·Out of Scope:

## 무엇을 지킬까 (링크만, 규칙 복제 금지)
- 관련 BR: BR-
- 판정/상태 원본 문서:
- 관련 ADR:

## 실제 예시 — '소득 모름' 판정 기능

- 사용자 가치: 소득구간을 모른다는 이유만으로 지원 불가로 보지 않는다.
- 경로: D2 / ST-02, ST-03 / BR-B01~B05 / AC-B01·AC-B02.
- **한 가지 책임:** `eligibility` 모듈이 학생 사실 스냅샷과 검증 규칙 트리를 평가.
- 범위 밖: 실제 기관의 소득 확인 시스템 연동/학생 서류 업로드.
- 테스트: `3학년+소득 UNKNOWN => 확인 필요`, `1학년+소득 UNKNOWN => 불가`, `검증되지 않은 규칙 => 가능 금지`.
- UI: 계산하지 않고 이유/원문·버전 표시.
- 미확정: 소득 값의 기준연도·단위는 실 공고를 보고 설계(OPEN-02).
