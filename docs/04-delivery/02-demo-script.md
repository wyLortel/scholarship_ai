# MVP 시연 대본 — 실행 절차와 리허설 (#42)

> 책임: **발표에서 무엇을 어떤 순서로 누르고 무엇을 말하는가.** 규칙은 [BR](../01-domain/04-business-rules.md), 수용 기준은 [AC](01-acceptance-tests.md), 시안별 데모 범위는 [`screens/README.md`](../../screens/README.md)가 원본이다. 이 문서는 ID만 인용한다.
>
> 시연 데이터는 모두 **TEST_ONLY 가상 공고**(`examples/fixture-notices.json`)다. 실제 장학금 규정이 아니다.

## 1. 실행 (한 장)

```bash
git clone <저장소> && cd scholarship_ai
docker compose up --build -d          # 백엔드 :8000, 프론트 :3000 — 실제 Rule Engine 경로(API_MOCK=0 기본값)
curl http://localhost:8000/api/health # {"status":"ok"}
open http://localhost:3000            # 홈에서 시작
```

- **mock 모드(`API_MOCK=1`)로 시연하지 않는다.** mock은 입력과 무관한 고정 응답이라 `모름 → 4구간 → 가능` 흐름이 보이지 않는다.
- 포트 3000이 이미 쓰이면 `lsof -nP -iTCP:3000 -sTCP:LISTEN`으로 확인하고 그 서버를 끈 뒤 다시 띄운다.
- 끝낼 때: `docker compose down`.
- 시연 전 점검: `docker compose run --rm backend pytest` 가 모두 통과하는지 본다.

## 2. 대표 흐름 (약 5분)

| # | 화면 · 누르는 것 | 보여 줄 것 | 멘트 |
|---|---|---|---|
| 1 | 홈 `/` | 검증된 공고 A·B·D 카드, **판정 배지 없음**, 미검증 C 없음 (BR-A05) | "이 화면의 공고는 모두 TEST_ONLY 가상 공고이고 실제 규정이 아닙니다. 아직 내 정보를 넣지 않았으니 가능·불가 표시도 없습니다." |
| 2 | 사이드바 **장학금 공고 목록** → 공고 A **내 정보로 조건 확인하기** → 3학년 · 모름 → 조건 확인하기 | 조건별 결과와 원문 문장·위치·확인 시각·공고 버전 (AC-B01) | "소득구간을 모르면 '불가'가 아니라 '확인 필요'로 남습니다." |
| 3 | 사이드바 **AI와 장학금 찾기** → 공고 A 선택 → 3학년 → 모름 | 질문마다 '왜 묻나요? 원문', 결과 **확인 필요**, 오른쪽 조건별 비교 (AC-B01, AC-B06) | "AI는 질문만 하고, 판정은 규칙 엔진이 합니다. 채팅 문장이 판정을 바꾸지 않습니다." |
| 4 | **다시 답하기** → 3학년 → 4구간 | 결과 **조건상 가능** + "실제 선정은 해당 기관이 판단" (AC-B03) | "가능은 선발 확정이 아닙니다." |
| 5 | **신청 준비하기** | `자료 준비 완료 · 제출 전`, 서류 체크리스트(재학증명서 발급처·안내, 가족관계증명서 '해당하는 경우'·'발급처 확인 필요'), 업로드 없음 (AC-C05) | "증빙서류는 올리지 않습니다. 어디서 발급받는지만 안내합니다." |
| 6 | **공식 사이트에서 직접 제출하기 (새 창)** → 새 창 닫고 돌아오기 | 상태가 그대로 `자료 준비 완료 · 제출 전` (AC-C07) | "제출은 공식 사이트에서 학생이 직접 합니다. 링크를 눌러도 제출된 것으로 바뀌지 않습니다." |

## 3. 보조 흐름 (각 1분)

| # | 화면 · 누르는 것 | 보여 줄 것 |
|---|---|---|
| A | 채팅 **다른 장학금 확인하기** → 공고 B → 재학 중 → 7구간 → 예 | OR 조건 '다음 중 하나만 충족하면 돼요', 다자녀로 충족 → 가능, 안 맞은 소득 조건은 흐리게 (AC-B04) |
| B | 채팅 **다른 장학금 확인하기** → 공고 D | 질문 없이 **확인 필요** + "이 공고의 조건을 아직 확인 중입니다. 사유: …" (AC-B05) |
| C | 사이드바 **장학금 추천 결과** → 3학년 · 4구간 · 재학 중 · 모름 → 공고와 비교하기 | 공고별 배지(A 가능, B 확인 필요, D 확인 필요)와 개수, 카드의 **자격 근거 보기** |

## 4. 하지 말 것

- '지원 가능 확정', '제출 완료', '접수 완료' 같은 말을 하지 않는다 (BR-C07).
- 가상 공고를 실제 장학금처럼 소개하지 않는다.
- 화면에 없는 기능(로그인, 초안 작성, 알림, 관리자 검토)은 "다음 단계"로만 말한다.
