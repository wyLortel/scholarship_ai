## 닫는 방법

`OPEN ID / 결정 / 공식 근거·실험 로그 / 반대 대안 / 승인자 / 날짜 / 반영한 PRD·BR·ADR·테스트 링크`를 적어 닫는다. 의미가 바뀐 ADR은 기존 결정을 조용히 고쳐 쓰지 말고 **새 ADR로 대체**한다.
