# typography.md — 글자 규칙

## 폰트
- 추천 스택: `Pretendard`, `Noto Sans KR`, `Apple SD Gothic Neo`, `system-ui`, `sans-serif`.
- 제공 스크린샷만으로 원본 폰트 이름을 **확정할 수 없다**. 디자인 폰트 라이선스와 로딩 방식은 팀이 별도 결정.
- 본문 표준 `16px / line-height 1.6`; 작은 메타 정보도 12px 아래로 내리지 않는다.

| 역할 | Token | Size / Line height | Weight | 예 |
|---|---|---|---|---|
| 대형 영웅 제목 | `--text-display` | 40/1.22 | 750 | '나에게 맞는 장학금' |
| 페이지 제목 | `--text-h1` | 30/1.3 | 750 | '내 신청 준비' |
| 섹션 제목 | `--text-h2` | 22/1.35 | 700 | '장학금 검색' |
| 카드 제목 | `--text-h3` | 18/1.4 | 700 | '지역 성장 장학금 B' |
| 일반 본문 | `--text-body` | 16/1.6 | 400–500 | 사용 안내 |
| 버튼/폼 | `--text-control` | 14/1.45 | 650 | '자격 근거 보기' |
| 보조 본문 | `--text-small` | 14/1.5 | 400 | 조건, 출처 |
| 라벨/상태 | `--text-label` | 12/1.45 | 650 | 상태 배지 |

## 규칙
- 제목은 의미상 h1→h2→h3 순서로. 단지 크게 보이려고 헤딩 수준을 바꾸지 않는다.
- 조건과 근거는 **가독성 우선**. '2학년 이상', '소득구간 5 이하', '불확실'을 같은 무게로 쓰지 않는다.
- Mobile 대형 제목은 28–30px 이하로 줄여 끊김을 방지.
- 버튼과 도움말은 서로 다른 계층. 중요 정보를 작은 메타 텍스트로 숨기지 않는다.
- 날짜와 원문 버전은 `tabular-nums` 또는 정렬에 적합한 숫자 표현을 사용한다.
