## 사용자 목표
**한 번 입력한 기본 사실**을 이후 장학금 조건 비교와 서류 초안에 재사용한다. 로그인 계정 정보와 장학금 비교용 프로필을 분리한다.

## 레이아웃 계약
- 인증: 마케팅 Hero와 독립된 2열 카드(정보/Google 로그인). 모바일에서는 세로 적층.
- 온보딩: 상단 페이지 목적 Hero → StepIndicator → 입력 폼 + 정보 사용 이유 패널.
- 각 단계당 Primary CTA 1개(`저장하고 다음 단계`, `저장하고 AI 시작`).

## 필수 입력 그룹(시안에서 읽은 항목)
1. 학적: 이름(표시명), 생년월일(필요할 때), 학교, 재학 상태, 학년, 전공/학과.
2. 성적: 직전 학기 평점, 평점 만점 기준.
3. 지역: 현재 거주지(시/도), 거주 기간(선택/모름).
4. 학자금 지원구간: 현재 확인 여부, 기준 시점.
5. 경험: 관심 분야, 키워드, 구체적 활동 기록(선택).

## 상태 규칙
- 초기값이 '모름'이라면 실제 미확인으로 저장. 0과 빈 문자열로 대체하지 않는다.
- 학점은 수치와 **만점 기준을 함께** 저장한다.
- 필수 항목 미입력은 해당 필드 바로 아래에 오류 메시지를 표시.
- 저장 완료 토스트 후 다음 화면으로 이동; 네트워크 실패는 값 유지+재시도.
- 개인정보 수집 목적/보관/삭제 안내는 실제 정책을 기반으로 구성해야 하며 시안만으로 정책 내용을 확정하지 않는다.

## 반응형·접근성
- 작은 화면에서는 2열 폼을 단일 열로 접는다.
- 단계 표시의 색만으로 진행 상태를 구분하지 않고 현재 단계 텍스트도 보여준다.
- Google 버튼은 실제 OAuth 연동 전에는 눌러도 인증 성공인 것처럼 연출하지 않는다.
