## 사용자 목표
나와 관련 있는 공고를 **빠르게 찾고, 왜 조건상 가능/확인 필요/불가인지 알며, 최신 공고 여부를 구분**한다.

## 화면 흐름
검색 결과 목록 → 장학금 상세(버전, 조건, 기관, 모집 상태) → '확인 필요'면 AI에게 질문 → 새 사실 확인 후 조건 재비교 → 준비 시작.

## 부품 조합
- `ScholarshipSearchBar` + `TabFilter`(필요한 경우).
- 결과 카드는 제목·기관·공고 버전·조건 요약·상태·행동 2개 이하.
- 상세 페이지는 `EligibilityConditionRow` 여러 개 + `SourceEvidenceCard` + `EligibilitySummary`.
- 버전이 바뀌면 `AnnouncementVersionDiff`에서 이전 vs 현재를 같은 영역에 표시.

## 상태표현 예
- 조건 충족: `✓ 대구광역시 거주 / 내 정보: 대구광역시 / 조건상 충족`.
- 미확인: `? 소득구간 5 이하 / 내 정보: 모름 / 확인 필요`.
- 불충족: `× 4학년 이상 / 내 정보: 3학년 / 현재 정보 기준 불충족`.
- 검증 대기: `! 원문 조건 검증 중 / 판정 보류`.
- 모집 미확인: 자격 배지 옆의 별도 `모집 상태 미확인`.

## 시연 데이터
- 01·06·07·15의 A/B/C/D 공고는 실제 모집공고로 제시하지 않는다.
- 실제 서비스 연결 전: 제목·근거·링크·판정과 함께 `시연용 가상 공고` 배지를 유지.
- 공식 URL이 없으면 검색 결과에서 `공식 페이지로 신청` 같은 행동을 표시하지 않는다.

## 예외/비동기
- loading: skeleton과 상태 설명.
- empty: '현재 조건에 맞는 공고를 찾지 못했습니다' + 조건 수정.
- error: '정보를 불러오지 못했습니다' + 재시도.
- stale: 공고 버전/프로필 수정으로 예전 결과면 `재판정 필요`.
