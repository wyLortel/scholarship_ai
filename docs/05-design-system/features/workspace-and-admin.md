## 학생 작업공간
- `/my-preparation`: 숫자 카드(답변 대기/초안 검토/준비 시작 전/공고 재확인) + 카드별 다음 행동.
- `/profile`: 계정과 장학금 비교용 프로필을 분리하고 저장/수정 이력을 다룰 수 있게 한다.
- `/notifications`: 전체/새로운 장학금/준비 진행/공고 변경으로 필터링한다.
- `/recheck`: 이전 판정의 공고 버전 vs 새 버전 차이와 재판정 안내.

## 알림에서 행동으로
- 미확인 사실 → **대화 이어가기**.
- 초안 부족 정보 → **초안 확인**.
- 공고 조건 변경 → **변경된 조건 검토**.
- 추천 → **자격 근거 보기**.
- 읽음/안읽음과 업무 상태는 별개의 축으로 관리.

## 관리자
- 학생용 헤더와 운영자 헤더 분리.
- 목록: `공고 ID / 버전 / 공식 원문 / 추출 결과 / 불일치 내용 / 검토 상태`.
- 상세: 좌측 원문(출처/단락), 우측 추출 조건과 수정·승인 폼.
- 승인된 것은 원문과 조건 추출의 정합성이지 학생 개인 자격이 아니다.
- 원문에 접근할 수 없다면 `원문 확인 실패`로 표시하고 승인 처리하지 않는다.
- '승인'·'반려'를 누르는 것은 실제 서버에 기록되는 별도 동작. 시연 UI에서는 실제 반영된 것처럼 알리지 않는다.
