# spacing.md — 간격·크기·레이아웃

> **제안 토큰**: 모든 값은 4px 단위. 시안에 보이는 대략적 크기를 기준으로 정한 시작점이며 Figma 측정 결과가 아님.

| Token | px | 흔한 용도 |
|---|---:|---|
| `--space-1` | 4 | 아이콘과 텍스트 사이 |
| `--space-2` | 8 | 배지 안쪽/작은 그룹 |
| `--space-3` | 12 | 컨트롤 내부 |
| `--space-4` | 16 | 버튼 간·컴포넌트 간 |
| `--space-5` | 20 | 컴팩트 카드 안쪽 |
| `--space-6` | 24 | 일반 카드/섹션 |
| `--space-8` | 32 | 카드 그룹 간 |
| `--space-10` | 40 | 넓은 섹션 간 |
| `--space-12` | 48 | 페이지 섹션 간 |
| `--space-16` | 64 | 헤더 다음 대형 간격 |

## 모서리
- `--radius-sm`: 8px / 작은 입력·칩.
- `--radius-md`: 12px / 버튼·배지·메시지.
- `--radius-lg`: 18px / 일반 카드.
- `--radius-xl`: 24px / Hero/온보딩/큰 카드.
- `--radius-pill`: 999px / pill 버튼, 상태 배지.

## 레이아웃
- Desktop 콘텐츠 최대 폭: `--layout-max=1280px`.
- Desktop 전체 안쪽 패딩: `--page-padding=28px`.
- 정보 탐색 2열: 메인 2~2.2fr / 보조 1fr, 간격 20px.
- 채팅 3열: 좌측 216px / 중심 minmax(0,1fr) / 우측 292px, 간격 16px.
- 카드 기본 padding: 24px. 정보 작은 카드: 16px.
- 데스크톱 헤더 높이 72px, 모바일 56px(초기안).
- 기본 버튼 높이 44px, 큰 버튼 48px, 입력 44–48px, 터치 타깃 최소 44×44px 권장.

## 반응형
- `>= 1200px`: 채팅 3열.
- `800–1199px`: 채팅 좌측 메뉴 축소/접기, 필요 시 요약 패널 접기.
- `<800px`: 콘텐츠 1열; 카드 1열·헤더 단순화·근거 패널 채팅 아래에 배치(또는 Drawer).
- `320–400px`: 칩 줄바꿈, 좌우 여백 12–16px, 모든 주요 버튼 폭 확보. 수평 스크롤로 정보를 읽게 하지 않는다.
- 대화 입력 상단 및 하단 여백과 모바일 키보드/안전 영역 고려. 시안의 306px 너비 화면에 그대로 묶지 않는다.
