# colors.md — 색상 시스템

## 출처와 정확도
스크린샷의 반복되는 시각 색상을 기반으로 한 **근사치 토큰**이다. Figma/디자인 소스에서 확인한 공식값이 아니다. HEX는 `frontend/src/design-system/design-tokens.css`가 구현 SSOT이다.

| 의미 | 토큰 | 초기값 | 사용 |
|---|---|---|---|
| 브랜드 파랑 | `--color-primary-600` | `#3267FF` | CTA, 링크, 선택 강조 |
| 브랜드 진파랑 | `--color-primary-700` | `#2454DB` | CTA hover |
| 보라 | `--color-violet-600` | `#6253F5` | 브랜드 그라디언트 끝 |
| 배경 | `--color-bg` | `#F7F9FE` | 앱 바탕 |
| 표면 | `--color-surface` | `#FFFFFF` | 카드, 모달, 헤더 |
| 연한 강조 | `--color-surface-tinted` | `#F2F4FF` | 메시지, 정보 박스 |
| 본문 | `--color-text` | `#172344` | 주요 정보 |
| 보조 텍스트 | `--color-text-muted` | `#667794` | 설명, 메타데이터 |
| 경계선 | `--color-border` | `#DCE5F7` | 카드, 입력 테두리 |
| 초점 | `--color-focus` | `#2F64FF` | 키보드 focus ring |

## 상태별 시맨틱 색상
| 상태 | 토큰 | 사용 | 필수 문구 |
|---|---|---|---|
| 조건상 가능 | `--color-positive-*` | 민트 배경/진초록 글씨 | '조건상 가능' |
| 확인 필요 | `--color-caution-*` | 연노랑/진갈색 글씨 | '확인 필요' |
| 불가 | `--color-negative-*` | 연분홍/진빨강 글씨 | '현재 정보 기준 불가' |
| 검증 대기 | `--color-neutral-*` | 회색 | '판정 보류' |
| 시연용 | `--color-demo-*` | 라벤더 | '시연용 가상 데이터' |
| 검토 필요 변경 | `--color-caution-*` | 경고/재판정 | '재판정 필요' |

## 금지 / 승인 규칙
- '확인 필요'를 '불가'의 빨간색으로 쓰지 않는다.
- 성공/경고/실패를 색만으로 구별하지 않는다(문구 + 아이콘 또는 상태 설명).
- 경고의 연한 배경에 일반 텍스트 대비가 부족하면 진한 의미색을 사용한다.
- Primary CTA는 파랑→보라 그라디언트. 스크롤 가능한 모든 카드에 그라디언트 버튼을 배치하지 않는다.
- 코드에서 HEX와 rgb()를 임의 추가하지 않고 `var(--color-...)`로 참조한다.
- AA 대비(일반 텍스트 4.5:1 권장) 및 색각 다양성을 브라우저에서 검증한다. 스크린샷을 그대로 따라 쓴 연회색 메타 텍스트는 대비 미달 가능성이 있다.
