# 비즈니스 불변식 — BR (단일 규칙 원본)

> 책임: 팀의 **업무 규칙을 중복 없이** 관리한다. 구체 계산 진리표는 `05-eligibility-policy`, 이벤트/전이표는 `06-state-machines`, 상세 테스트는 `../04-delivery/01-acceptance-tests`에 둔다.
> 분류: `[DEFINED]` 팀 제공 내용, `[SAFETY]` 정의를 안전하게 실행하기 위한 정책 제안(팀 승인 필요), `[OPEN]` 미확정.

## 불변식의 사용 예

- UI 구현: BR-B02, B06, C07 참조 → `가능` 설명을 임의로 바꾸지 않는다.
- Rule Engine 구현: BR-B01~B09 참조 + 실제 계산은 05번 문서.
- 수집 구현: BR-A01~A09 참조 + 데이터 버전·상태는 06·08번 문서.
- 초안 생성: BR-C04~C08 참조 + 09번 문서의 입력/출력/거부 조건.
- 알림 구현: BR-N01~N03 참조 + dedupe와 동의 정책 확인.

**변경 절차:** 이 BR 문서가 승인된 경우, 코드를 먼저 고치고 규칙을 뒤늦게 합리화하지 않는다. 변경 의도 → 근거 → 테스트 → 팀 승인 → 변경을 연결한다.
