# 팀 업무 용어집 — 유비쿼터스 언어

> 책임: 논쟁의 여지가 있는 **용어 하나의 뜻**을 고정한다. 판정 계산은 `05-eligibility-policy.md`, 상태 전이는 `06-state-machines.md`에서만 정의한다.

| 용어(권장 코드명) | 정확한 뜻 | 다른 말과 혼동 금지 |
|---|---|---|
| `ScholarshipProgram` 장학금 프로그램 | 기관이 운영하는 장학금 제도 자체 | 특정 연도의 모집 공고와 다름 |
| `Notice` 모집 공고 | 어느 기관/모집 회차의 공식 신청 안내 | 뉴스/블로그의 소개글과 다름 |
| `NoticeVersion` 공고 버전 | 특정 시점 공식 원문과 첨부·조건 묶음 | 새로 수집한 시각이 곧 새 버전이라는 뜻 아님 |
| `OfficialSource` 공식 출처 | 장학금 기관이 승인·운영하는 원문 위치 | 검색 결과/AI 요약·커뮤니티와 다름 |
| `SourceCandidate` 출처 후보 | 새 기관/사이트를 발견해 조사할 대상 | 승인된 수집 대상과 다름 |
| `Evidence` 원문 근거 | 공고 버전+파일/문장/페이지/위치+확인 시점 등 추적 단서 | LLM의 추측 문장과 다름 |
| `ExtractedCondition` 추출 조건 | AI/파서가 뽑은 **후보** 규칙 | 검증된 규칙으로 바로 사용 금지 |
| `VerifiedRuleSet` 검증된 규칙 묶음 | 공식 원문과 연결되고 승인된 구조화 조건 | 부분 추출 성공만으로 공고 전체 완료 아님 |
| `StudentFact` 학생 사실 | 학생이 입력·확인한 프로필 항목과 기준 시점/출처 | 공식 기관이 증명했다는 뜻 아님 |
| `MissingFact` 정보 미입력 | 필요하지만 입력되지 않음 | `FAIL`, 숫자 `0`, 비적격과 다름 |
| `PASS / FAIL / UNKNOWN` 조건별 결과 | 특정 규칙을 특정 학생 정보로 평가한 3가지 내부 결과 | 최종 전체 결과와 다름 |
| `ELIGIBLE` 지원 가능 | 검증한 조건·입력 범위에서 필요한 자격 조건 충족 | 장학생 **선발 확정** 아님 |
| `INELIGIBLE` 지원 불가 | 근거 있는 필수 자격 미충족 확인 | 모집/예산 종료와 동일 개념 아님 |
| `NEEDS_REVIEW` 확인 필요 | 누락·문장 모호·공고 검증 이슈 등으로 단정 불가 | 불가나 선정 대기와 다름 |
| `institution_confirmation` 기관 확인 필요 | 공식 기관 해석·확인이 필요하여 사용자가 답만으로 해결 불가 | 내부 검토자 검토와 다름 |
| `VerificationDecision` 내부 검토 결정 | 원문에 맞춰 추출값 승인/수정/반려 | 기관의 신청 승인과 다름 |
| `PreparationCase` 신청 준비 건 | 특정 학생·공고 버전에서 체크리스트/초안 준비를 이어가는 업무 단위 | 공식 접수 건과 다름 |
| `QuestionRequest` 추가 질문 | 어떤 UNKNOWN을 풀기 위해 이유·대상 사실·응답을 묻는 항목 | 임의 잡담 질문과 다름 |
| `Checklist` 서류 체크리스트 | 최신 공식 공고에서 요구하는 서류/발급 방법/확인 사항 | 실제 개인 증빙 파일이 아님 |
| `Draft` 작성 초안 | 제공·확인된 사실과 공고 문항에 기초한 문안 | 최종 제출 서류/기관 승인 문서 아님 |
| `Prepared` 준비 완료 | 제공할 자료가 준비되고 남은 미확인 항목이 명시됨 | 기관 공식 접수(`Submitted`)와 다름 |
| `LatestCheck` 최신성 확인 | 시각과 성공·실패·변경 여부를 포함한 확인 결과 | 단순 '지난주 수집'과 다름 |
| `NotificationRecord` 알림함 항목 | 새·변경 공고 안내를 위해 남긴 학생별 기록 | FCM 기기 푸시 전달 성공과 다름 |
| `Thread / Run / Checkpoint` AI 실행 상태 | Agent Server/그래프의 대기와 복구 기술 단위 | 도메인의 `PreparationCase`를 대체하지 않음 |

## UI 한국어 문구 (초안)

- `ELIGIBLE` → **지원 조건 충족(기관 최종 심사 별도)**
- `INELIGIBLE` → **지원 조건 미충족** + 이유·근거
- `NEEDS_REVIEW` → **확인 필요** + 부족한 정보/문의처/검토 상태
- `PREPARED_WITH_OPEN_ITEMS` → **자료 준비 완료 · 확인할 항목 남음**
- `PREPARED` → **신청 자료 준비 완료 · 공식 제출은 직접 진행**

마지막 2개 문구·내부 코드명은 **실행 계약을 위한 제안**이며 공식 제품 카피는 팀 승인 필요.
