# 공고의 공식성·버전·근거 관리 기준

> 책임: **공고 하나의 신뢰 가능한 변경 이력**. 자격 계산은 `05-eligibility-policy.md` 참조.

## A 영역의 판단: 세 가지를 혼동하지 않는다

1. `source_is_official`: 발견한 URL/기관이 공식 공고 출처인가?
2. `fetch_outcome`: 해당 회차 수집이 신규/변경/동일/실패 중 무엇인가?
3. `rules_are_verified`: **이번 원문 버전**에서 추출한 자격 규칙이 정확한가?

**예:** 출처는 공식(`true`)이고 수집은 변경(`CHANGED`)되었지만 새 조건은 검토 중(`REVIEW_PENDING`)일 수 있다. 이때 신버전의 `가능` 추천은 금지.

## 제안 필드와 불변식

| 필드 | 의미 | 규칙 |
|---|---|---|
| `institution_id` | 공식 기관 | 후보/승인 구분 |
| `official_url` | 원문 공식 위치 | 뉴스 기사 대체 불가 |
| `notice_id` | 모집 회차 식별자 | 다른 연도/차수를 무분별하게 합치지 않음 |
| `notice_version_id` | 불변 원문 스냅샷 식별자 | 새 조건 = 새 버전 |
| `source_content_hash` | 비교용 콘텐츠 해시 | 해시 같음만으로 '최신 접속 성공' 주장하지 않음 |
| `checked_at` | 사이트 확인 시각 | 실패 시 성공 시각을 덮어쓰지 않음 |
| `fetched_at` | 바이트/첨부 확보 시각 | 원문 검증 시점과 다름 |
| `file_id`, `page_or_span` | 증거 위치 | 원문과 함께 보관 |
| `verification_status` | 후보·검토·검증·반려 | 색인 노출 통제 |
| `verified_at/by` | 검증 시점/주체 | 자동 검증과 수동 검토를 구별 |
| `supersedes` | 어느 이전 버전을 대체했는지 | 이전 판정의 근거 보존 |

## 회차별 업무 동작

**신규:** 새로운 모집 회차를 발견 → 공식 확인 → 원문/첨부 영속화 → 규칙 후보 추출 → 원문 검증 → 검증 시만 색인·판정.

**변경:** 기존 공고에 새 원문 → 해시 비교와 메타데이터 확인 → 새 버전 생성 → 후보 추출/검증 → 기존 평가를 새 버전 기준 재확인. **구버전 삭제 금지**.

**변경 없음:** 해당 회차에서 원문이 성공적으로 확인되고 비교 기준상 동일 → 새 버전/재분석 없이 종료. 유효한 마지막 성공 시각은 갱신할 수 있으나 무작정 검증시각을 덮어쓰지 않음.

**접속/분석 실패:** 실패 사유·재시도·시각 기록, 이전 버전은 과거 근거로 유지하되 새 버전 확인 성공으로 표기 금지.

## ‘근거 검증’이란 (제품 정책 제안)

- 각 규칙에 원문 인용 위치와 정확한 연산자, 대상, 비교 단위, 적용 범위(연도/학적)가 있는가?
- 단일 문장 외에 단서·표/별첨·예외조항을 놓치지 않았는가?
- 공식 PDF/HWP와 본문이 충돌하면 어느 것이 우선인지 정해져 있는가?(OPEN-03)
- 표현이 모호하거나 정량 조건이 추출 안 되면 **검토 요청**, 임의 숫자 보정 금지.
- 검증 완료 이후에만 공개 검색·추천용 인덱스와 판정 입력으로 전환.

## 다운스트림 무효화

`NoticeVersionSuperseded` → 영향받는 `VerifiedRuleSet`/`EligibilityAssessment`/`PreparationCase`/`Draft`를 식별한다. 이전 결과는 삭제가 아닌 `STALE` 표시. **재평가가 성공하지 않았다면 새 조건의 결과인 것처럼 보여주지 않는다.** 구체 작업 재개(초안 폐기/재사용)는 OPEN-04.

## 외부 출처 특유의 문제

- robots.txt, 기관 이용약관, 요청 간격, 변경 공고 접근권한, 공공데이터 API 보존 조건은 출처마다 검증 필요.
- 콘텐츠 해시만으로 '원문의 의미가 동일하다'를 확정하기 어렵고, 광고/동적 요소 변화는 거짓 변경일 수 있다. 본문 정규화·첨부 버전 비교 방법은 수집 PoC 후 ADR.
- 원문 확인과 임베딩 유사도는 독립. 어떤 벡터 결과도 증거 anchor를 대신하지 않는다.
