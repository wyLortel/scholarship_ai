# 화면 시안 (wireframe) — 구속력 없는 참고 자료

> 2026-11-18 팀원이 만든 화면 시안이다. **디자인 방향 참고용**이며 요구사항의 원본이 아니다.
> 무엇을 보여줘야 하는지는 [UX 정보 계약](../docs/02-product/03-UX-contract.md), 기능·범위는 [PRD](../docs/02-product/01-PRD.md)가 정한다. 충돌하면 그 문서가 우선한다.

## 읽을 때 주의

- **방향:** AI 상담(채팅)이 주 화면이고, 대화 옆에 공고·조건별 결과·원문 근거를 같이 보여준다. 단, **판정은 Rule Engine 결과를 그대로 표시**하고 AI 문장은 질문·설명만 한다(CLAUDE.md §2-4, AC-B06).
- **가상 데이터가 다르다:** 시안의 공고(캠퍼스 희망 장학금 A, 지역 성장 장학금 B, 미래 연구 장학금 C)와 학생 값(대구 거주, 평점 3.8)은 그림용이다. 구현과 테스트는 [`examples/fixture-notices.json`](../examples/fixture-notices.json)(#24)을 기준으로 한다.
- **문구:** 시안의 문구도 UX 계약의 카피 규칙(가능/불가/확인 필요, 준비 ≠ 제출)을 따른다. 시안에 있다고 그대로 쓰지 않는다.
- 모든 시안 데이터는 `TEST_ONLY` 가상 데이터다. 실제 기관·학생 정보가 아니다.
