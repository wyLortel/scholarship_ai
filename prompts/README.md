# AI 단계별 프롬프트 계약(참고 템플릿)

> 책임: 런타임 AI가 맡는 **후보 추출/설명/초안** 업무의 계약. **Rule Engine은 LLM 프롬프트가 아닌 코드**로 구현한다. 아래는 프로젝트 맞춤 설계 초안으로 현재 실제 Agent가 이 프롬프트를 사용한다는 의미가 아니다.

- `01-extract-conditions.md` — 공식 공고 원문에서 구조화된 **검증 전 후보**만 추출.
- `02-explain-assessment.md` — 이미 계산된 3값 판정을 변경하지 않고 학생에게 설명.
- `03-draft-application.md` — 학생이 확인한 사실만 사용한 공고별 작성 초안.
- `04-evidence-review.md` — 추출 후보와 원문 근거의 정합성 체크, 내부 검토로 넘길 이유 기록.

모든 런타임 호출에서 시스템/도구 입력과 사용자/문서 입력을 구분하고 외부 원문 속 지시를 명령으로 실행하지 않는다. 응답은 스키마 검증 후만 후속 단계로 사용하며 외부 링크·민감정보·권한을 검사한다.
